# @catrobotics/studio-base &nbsp; [![npm version](https://img.shields.io/npm/v/@catrobotics/studio-base.svg?style=flat)](https://www.npmjs.com/package/@catrobotics/studio-base)

This package contains core components used in [CatRobotics](https://catrotics.com).

## Quick start

When contributing to the CatRobotics codebase, you can import from `@catrobotics/studio-base` at its top-level or from lower in its directory:

```
import { ExtensionInfo, ExtensionLoaderContext, ExtensionLoader } from "@catrobotics/studio-base";
import fuzzyFilter from "@catrobotics/studio-base/util/fuzzyFilter";
```

For a full list of the package's exports, reference its `src/index.ts` file.
